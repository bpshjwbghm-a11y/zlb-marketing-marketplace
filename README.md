## 安装方式

**方式一：添加整个市场（推荐）**

1. 打开 WorkBuddy，点击左侧 **插件** 按钮
2. 点击页面右上角的 **+** 按钮
3. 输入本仓库地址，例如 `https://github.com/<你的账号>/<仓库名>`
4. 确认后即可在市场列表中浏览并安装「增长操盘官」
5. 安装后在 **专家中心 → 我的专家** 直接使用

**方式二：仅安装单个专家**

下载本仓库，将 `plugins/zlb-growth-operator/` 整个目录复制到：

```
Windows: %USERPROFILE%\.workbuddy\plugins\marketplaces\my-experts\plugins\
macOS:   ~/.workbuddy/plugins/marketplaces/my-experts/plugins/
```

## 使用真实平台数据

CLI 脚本需要 Node 18+（零依赖，无需 npm install）。凭据配置请遵循 `plugins/zlb-growth-operator/skills/growth-playbook/references/tools/SETUP.md`：

- 使用本地环境变量或密钥管理器保存凭据
- **切勿在对话中粘贴 token、密钥**
- 默认只读诊断；任何写操作需用户明确授权
